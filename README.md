# 🛒 Cashier & Distro Inventory

Cashier & Distro Inventory is a full-stack web application built with **Laravel 10** and **Breeze**. It helps clothing stores manage sales transactions, inventory, discounts, vouchers, and customer data in one system.

## ✨ Features

- 🛍️ Sales transaction management
- 📦 Product & inventory management
- 🎟️ Discount and voucher system
- 👥 Customer management
- 📊 Sales reports
- 🔐 Authentication & role management

## 🛠️ Tech Stack

- Laravel 10
- Laravel Breeze
- PHP
- MySQL
- Tailwind CSS
- JavaScript

## 🚀 Installation

```bash
git clone https://github.com/yourusername/cashier-distro-inventory.git
cd cashier-distro-inventory

composer install
cp .env.example .env
php artisan key:generate

php artisan migrate

npm install
npm run dev

php artisan serve
```
